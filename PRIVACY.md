# Eaglets Code privacy policy

Last updated: 27 November 2026

Eaglets Code is a block and Python programming app for the Eaglets robot kit. Many of the people using it are children, so we built it to collect nothing.

## The short version

- **No accounts.** Nobody signs up, logs in, or gives a name, email, age or school.
- **Nothing is sent to us.** The app doesn't send your programs, settings or any other information to Eaglets or anyone else.
- **No analytics, ads or trackers.** No cookies for tracking, no advertising, no third-party analytics or crash reporting.
- **No camera, microphone or location.** The app never asks for them.

## What stays on your computer

So that work isn't lost, the app saves a few things **only on the computer you're using**:

| What | Where | Why |
|---|---|---|
| The program you're working on (blocks or code) and its name | Browser / app local storage | Autosave, so a closed window doesn't lose work |
| Instructor settings (motor direction, sensor tuning) and Beginner mode on/off | Browser / app local storage | So the classroom setup is remembered |
| Project files you choose to save (`.eaglets`, `.py`) | Wherever you save them | You asked for a file |

Programs and settings you run are also copied onto the **robot** over USB, because that's how the robot runs them. That data stays on the robot's Raspberry Pi Pico.

None of this leaves the device unless you copy or share the files yourself. To delete it, clear the site data for Eaglets Code in your browser, or uninstall the desktop app and delete its data folder, and delete any project files you saved.

Avoid putting personal information (a full name, address, phone number) into project names or program text, especially on shared camp or school computers.

## USB access

To talk to the robot, the app uses your browser's or operating system's serial (USB) access. You choose the device each time, or in the desktop app it picks the connected robot. The app only talks to the robot you connect. It doesn't read other devices or files.

## Websites and downloads

If you use a copy of Eaglets Code hosted on a website, or download the installer from one, that website's host may keep standard server logs (such as IP addresses) as part of running the site. Eaglets doesn't use those logs to identify or track anyone. Links in the app or its guides to other sites (for example micropython.org) open in your normal browser and are covered by those sites' own policies.

## Children

Eaglets Code doesn't knowingly collect personal information from anyone, including children under 13 (or the equivalent age where you live). Because nothing is collected, there's nothing for a parent to review or delete on our side. Data saved on a device can be removed as described above.

This is how we meet the Children's Online Privacy Protection Act (COPPA) in the US, the GDPR and UK GDPR (including the UK Age Appropriate Design Code), and similar laws: we don't process children's personal data at all.

## Schools and camps

Eaglets Code doesn't receive student records or education data, so it doesn't act as a "school official" or data processor for a school or camp. If your organisation needs a signed student-data privacy agreement, contact us.

## Changes

If a future version ever changes how data is handled (for example, adding optional online features), we'll update this policy before that version is released, change the date at the top, and make the change clear in the release notes. Any feature that collects personal data from children would require verifiable parental consent first.
